# SAMMENA CMS Domain Rules

## Content lifecycle

DRAFT -> REVIEW -> APPROVED -> PUBLISHED -> ARCHIVED

## Rules

- Draft and review content is private to authorized staff.
- Only authorized editors can submit content for review.
- Only authorized approvers can approve content.
- Publishing records who published and when.
- Scheduled publishing requires an explicit publish time.
- Expired announcements become unavailable to the public without deleting their audit history.
- Slugs must be unique within their content type.
- Public responses contain only approved, publishable fields.

## Media

Media metadata belongs to the CMS. Sensitive files belong in private storage and require authorization.
