# Sammena Motion System

The Sammena interface uses motion to communicate hierarchy, continuity and feedback.

## Motion layers

### Ambient
Slow, low-amplitude background/depth movement. Never competes with text.

### Structural
Section entrances, page transitions and navigation continuity.

### Interactive
Hover, focus, press, drag and selection feedback.

### Narrative
Scroll-linked storytelling, progressive timelines and connected visual sequences.

### Cinematic
Hero introductions and major product moments. Reserved for high-value surfaces.

## Signature sequences

### Hero reveal
Atmosphere → brand mark → headline → supporting copy → primary action → secondary visual.

### Scroll reveal
Viewport entry → depth separation → content reveal → relationship line → next section.

### Admission journey
Step activation → progress transition → field group reveal → validation feedback → confirmation choreography.

### Decision state
Review → decision → state morph → audit confirmation → notification acknowledgement.

## Interaction rules

- Use transform and opacity where practical.
- Avoid unnecessary layout shifts.
- Avoid infinite attention-seeking animations.
- Do not animate sensitive or critical information in ways that impair reading.
- Provide reduced-motion equivalents.
- Keep mobile motion lighter than desktop when complexity would hurt usability.

## Timing language

Use short transitions for controls, medium transitions for component changes, and longer choreography only for narrative/cinematic sequences. Exact timings should be established centrally in the implementation rather than scattered through components.

## Definition of done

Motion is complete only when it passes:

- usability review
- responsive review
- keyboard/focus review
- reduced-motion review
- performance review
- visual consistency review
