# SAMMENA Application Tracking UX

## Applicant experience

A parent should be able to enter an application reference and securely view only the approved status of their own application.

## Status timeline

1. Application received
2. Under review
3. Assessment (if applicable)
4. Decision
5. Enrollment

## Status details

The public-facing timeline should show:
- current status
- last meaningful update date
- next expected action where appropriate
- school contact route

It must not expose:
- internal review notes
- staff identities unless intentionally public
- other applicants
- database IDs
- private documents without authorization

## Error states

- invalid reference
- unauthorized access
- expired session
- temporarily unavailable

Errors should be helpful without confirming sensitive information.
