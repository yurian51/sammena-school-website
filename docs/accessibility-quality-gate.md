# SAMMENA Accessibility Quality Gate

## Baseline

- Semantic headings in logical order
- Keyboard-accessible navigation and controls
- Visible focus states
- Form labels and required states
- Meaningful link/button labels
- Alternative text for meaningful images
- Decorative images hidden from assistive technology
- Sufficient color contrast
- Reduced-motion support
- Responsive text and touch targets
- No information conveyed by color alone

## Testing

Run automated accessibility checks on critical routes and manually review keyboard navigation on desktop and mobile viewport behavior.

## Critical routes

- /
- /about
- /academics
- /admissions
- /admissions/apply
- /news
- /resources
- /calendar
- /portal
- /contact

Accessibility issues affecting navigation, forms, admissions or essential information are release blockers.
