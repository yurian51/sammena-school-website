# SAMMENA Website Analytics Events

## Core events

- `admission_cta_clicked`
- `application_started`
- `application_step_completed`
- `application_prepared`
- `resource_viewed`
- `resource_download_clicked`
- `news_opened`
- `event_opened`
- `calendar_opened`
- `portal_opened`
- `search_performed`
- `contact_clicked`
- `phone_clicked`

## Event properties

Include only non-sensitive product analytics such as route, content category and UI location. Do not send student names, phone numbers, email addresses, application documents, grades or financial information to analytics systems.

## KPIs

- Admissions CTA conversion
- Application starts/completions
- Resource engagement
- Search success
- Contact conversion
- Portal entry rate
- Top public content

Analytics should be consent-aware and privacy-preserving where required.
