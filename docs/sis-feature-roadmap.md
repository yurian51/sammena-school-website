Build Sammena as a school operating platform, not only a public website.

## Definition of done

Each feature should have, where applicable:
- UI and responsive states
- Domain types
- Validation
- Business rules
- Service layer
- Repository contract
- Persistence adapter
- Role/permission checks
- Audit events for sensitive actions
- Error/loading/empty states
- Documentation

Testing, lockfile synchronization, CI hardening, production migration, security review and deployment are final release gates after the feature set is complete.
