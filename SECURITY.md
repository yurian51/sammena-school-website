# Security Policy

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

For security issues affecting Sammena School systems, contact the project owner privately through the repository owner's verified GitHub contact channels. Include the affected route or component, reproduction steps, impact, and any relevant logs without including passwords, tokens, student records, or other personal data.

## Security expectations

- Private student and guardian records must never be exposed through public routes.
- Authorization must be enforced server-side.
- Secrets must remain outside source control.
- Sensitive mutations should be attributable to an authenticated actor.
- Production claims must be backed by verification evidence.
